Key shifts for 18–24 demographic

Micro-accounts dominate filtered reach. uh1269 (471 followers) holds 33% share of voice reaching 1.3M. f2.memo (44 followers) reached 378K. Clearest evidence of algorithmic amplification targeting young feeds.
TikTok's positive skew drops when filtered. Full set: 29% positive. Filtered: 20% positive, negative rises to 23%. The broader set was diluted with softer posts — filtered content is more hostile.
News links cluster around Jewish press. Top links all point to jpost.com (Jerusalem Post). Reactive reporting coverage adds volume and search legitimacy to the topic.
PragerU and Destiny both appear. Ideologically opposing YouTube channels with massive young-adult audiences — this topic is embedded in the 18–24 debate ecosystem from multiple angles.
LinkedIn at scale is new. 94 mentions ties X — institutional and campus-level discussion (student unions, university departments) is a significant parallel channel in the filtered set.
07

The two-layer reach model

LAYER 01 — 87% of full set
The noise / exposure layer
Solidarity posts, viral tags, and geopolitical content that mentions antisemitism tangentially. High reach (75M), softer framing. Primary passive exposure for 18–24 audiences. Not captured in filtered set.
LAYER 02 — 13% / this dataset
The signal / ideological layer
Direct content using #antisemitism, #jewish, specific incident links. Smaller reach (24M) but more explicit and more negative. Where ideological formation happens in more engaged users.
CONNECTION MECHANISM
How they bridge
#fyp surviving in both layers confirms TikTok's algorithm actively bridges the two. Passive exposure in Layer 1 creates familiarity; Layer 2 converts engaged viewers into active consumers of explicit content.
BLIND SPOTS
What neither layer captures
Telegram private channels, Instagram (Meta API gap), coded language, and comment-section content. True exposure across both layers is higher than either dataset shows.
Cross-period trend: Both current and prior periods (Mar 15–29) show nearly identical sentiment ratios — 24% negative, 5% positive in both filtered periods. This is not a spike event but a sustained, structural pattern of content reaching young audiences.
08

Data limitations

No direct age segmentation. Brand24 does not provide demographic breakdowns. The 18–24 inference is based on platform demographics and influencer account characteristics — not confirmed age data.
Keyword tracking only. Both filtered and full datasets track the keyword "antisemitism." Coded language and dog-whistles are invisible to this method. True exposure is higher.
Meta API gap. Instagram and Facebook show 0 mentions in both datasets — almost certainly a platform API access limitation, not a true absence.
Filter methodology opaque. The specific Brand24 filter criteria that reduced 17K to 2,210 mentions is not described in the export. Interpreting what "more direct" means requires knowing the filter logic.
